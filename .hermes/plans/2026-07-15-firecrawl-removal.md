# Plan: Remove Firecrawl from TripTide Codebase

**Date:** 2026-07-15
**Status:** Ready to execute
**Estimated effort:** ~30 min

---

## Summary

Remove all Firecrawl dependency, client code, sync runner, and references from the TripTide codebase. The good news: **Firecrawl is already isolated** — it is NOT used by the main `hybridEngineOptimized.ts` engine, any API routes, or the database schema. It lives in a few dedicated service files and test scripts that can be cleanly removed.

The `hybridExtractor.ts` (the only file besides the firecrawl clients themselves that imports Firecrawl) will be removed entirely, and its caller in `hybridEngineOptimized.ts` already uses the OpenCode generator directly.
