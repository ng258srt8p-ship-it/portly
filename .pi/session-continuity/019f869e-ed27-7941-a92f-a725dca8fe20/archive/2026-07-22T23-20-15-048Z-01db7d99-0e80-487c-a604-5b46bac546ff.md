## Do Not Repeat / Lessons Learned

1. **Hermes requires ≥64K context window**: Setting `max_context_window` to anything below 65536 will cause Hermes to fail initialization with "context window below minimum 64,000 required".
2. **Per-model settings via admin API are persistent**: Unlike global settings file edits (which get overwritten on server restart), per-model settings applied via `PUT /admin/api/models/{id}/settings` survive restarts.
3. **Settings changes require model reload**: The admin API returns `requires_reload: false` even when the advertised `max_model_len` doesn't change until an unload/reload cycle. Always reload after context window changes.
4. **Server restart needed after global settings file edit**: The server re-reads `settings.json` on startup, overwriting any manual edits made while it was running. Always use the admin API for runtime changes.
5. **Cookie authentication expires on server restart**: The `/tmp/omlx_cookies.txt` file becomes invalid after a server restart. Always re-authenticate with `POST /admin/api/login`.
6. **oMLX patches in app bundle may be overwritten by updates**: Any oMLX update will wipe the MTP dequantization patches in `/Applications/oMLX.app/Contents/Resources/omlx/patches/`. Recovery requires re-applying the patches or re-downloading the `.biases` tensors.
