## Do Not Repeat / Lessons Learned

- **Edit tool uniqueness:** When fixing identical code blocks in multiple locations, always include sufficient surrounding context (function names, preceding lines) to make `oldText` unique. Generic patterns like `const prices = doubles.map(...)` failed until function signatures were included.
- **Inline styles vs className:** When adding skip-to-content links, mixing className with inline styles creates maintenance debt. Prefer CSS classes or a single clean approach.
- **Grep exit codes:** `grep` returns exit code 1 when no matches found — script continues but status is ambiguous. Always check exit codes explicitly in verification scripts.
- **Layout.tsx rewrite:** The initial edit approach created a duplicate preload link and messy inline styles. Rewriting the entire file cleanly was faster than patching.
